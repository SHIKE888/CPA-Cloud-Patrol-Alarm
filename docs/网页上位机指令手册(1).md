# 🎮 QGimbal 网页上位机指令手册

适用于本工程 **Run 2.0.2-dm_mc2.8**，依据当前设备命令实现整理。命令输入位置为官网上位机中央终端，不是 Windows CMD 或 Linux 终端。

## 🚀 连接与输入

1. USB 连接电脑，关闭占用串口的循环脚本和其他串口工具。
2. 打开 <https://www.qdrive.com.cn/tools/web-host/gimbal/>，选择115200并点击“连接设备”，选择板卡 USB 串口。
3. 在中央终端输入命令并回车，一次一条，等待回显。不要复制 `QGimbal:/$` 提示符。

首次连接建议逐条读取：

```text
version
info
status
diag
config --list
```

**本文示例不是要求按顺序全部执行。运动命令会改变运动目标，设零和中心命令会改变标定。** 参数以当次读回为准，网页卡片和历史截图不是精确备份。

## 📡 查询与诊断

| 命令 | 作用 |
|---|---|
| `version` | 软件版本、硬件型号、Run / Observe 目标 |
| `info` | 双轴 CAN 总线和 ID、IMU 就绪状态、Pitch 限位 |
| `status` | 使能、自稳、模式、IMU姿态及速度、关节角度、速度、电流、电压 |
| `diag` | Fault、控制源、反馈年龄及错误、IMU原始值、控制周期、映射、方向、零点、机械中心 |
| `config --list` | 双轴 PID、电流限值、UART波特率、速度限值、Pitch范围 |
| `config --help` | 参数命令语法说明 |
| `help` | 终端命令帮助；可用 `help ctrl` 查询命令项 |
| `clear` | 发送终端清屏控制序列；网页是否渲染取决于页面，可直接使用网页“清屏”按钮 |

`status` 的 `Angle` 为关节角，`IMU Angle` 为IMU姿态，两者不是同一坐标。`diag` 中 `zero_raw` / `mechanical_center` 仅打印5位小数，不等价于无损标定备份。`config --list` 不列出映射与方向，用 `diag` 查看。

出现 `STALE`、`nan`、`enabled=unknown` 表示反馈不可用；不能按零值理解。故障发生后先保存 `diag` 和 `status` 回显，再决定是否清故障或重启。

## 🎛️ 使能、失能与五种模式

| 命令 | 作用与前置条件 |
|---|---|
| `enable` | 双轴使能；需Run固件、有效反馈/IMU、有效零点及方向确认、无锁存故障，且Pitch在允许范围内 |
| `disable` | 双轴失能、清除运动目标与自稳状态；停止后不主动保持位置 |

所有运动指令参数顺序固定为 **Yaw、Pitch**；两轴共用模式，不支持一轴速度模式、另一轴角度模式。失能时运动指令被拒绝。

| 模式与语法 | 单位 | 示例及含义 |
|---|---|---|
| `ctrl current Y P` | A | `ctrl current 0 0`：双轴零电流 |
| `ctrl speed Y P` | rpm | `ctrl speed 10 10`：双轴正向速度10rpm |
| `ctrl angle Y P` | rad | `ctrl angle 0 0`：双轴绝对零角目标 |
| `ctrl step_angle Y P` | rad | `ctrl step_angle 0.2 0`：Yaw增加0.2rad步进目标，Pitch增量0 |
| `ctrl low_speed Y P` | rpm | `ctrl low_speed 0.2 0`：Yaw低速0.2rpm，Pitch低速目标0 |

同样支持等号和逗号形式：

```text
ctrl speed=10,10
ctrl angle=0,0
```

`step_angle` 相对内部目标累加，不保证每次从当前实测位置起步；重复发送会累计。`low_speed` 通过持续积分位置目标实现低速，与普通速度环模式不同。

常用停止方式：

```text
ctrl speed 0 0
```

这仍保持使能且切到速度模式，不等于角度保持。要停止输出并失能：

```text
disable
diag
```

角度换算：1rad≈57.2958°，0.9rad≈51.5662°，0.2rad≈11.4592°。速度命令不是rad/s。单条运动命令持续有效，网页没有内置等待时间、位置条件或匀加减速循环命令；条件循环由外部脚本实现。

## 🧭 自稳与IMU复位

| 命令 | 作用 |
|---|---|
| `enable_stability` | 开启自稳；须已使能、IMU就绪且当前不是电流模式 |
| `disable_stability` | 关闭自稳 |
| `config zero_pos --imu` | 复位IMU姿态参考；自稳开启时拒绝，不是机械设零，也不是重新估计陀螺零偏 |

例如先进入角度模式并停稳，再开启自稳：

```text
enable
ctrl angle 0 0
```

观察双轴到位停稳后，单独输入：

```text
enable_stability
status
```

`ctrl angle 0 0` 会主动回零，不是仅切模式。普通模式零角依据关节零点，自稳模式位置目标依据IMU世界参考；自稳开启后再发送零角目标可能主动运动。

复位IMU前关闭自稳，建议先失能并保持底座静止：

```text
disable
config zero_pos --imu
status
```

`.8` 自稳位置目标会做主值和可达范围处理；机械限位期间目标与实际姿态可能不同，倾斜时也可能正常双轴联动。

## 🔧 参数修改

普通参数修改先 `disable`，修改后读回；未 `store` 的修改通常仅在RAM，重启恢复已保存值。

两种等效写法：

```text
config limit.speed 100
config limit.speed=100
```

| 参数键 | 含义 / 源码允许范围 |
|---|---|
| `pid.speed.kp.yaw`、`pid.speed.ki.yaw`、`pid.speed.kd.yaw` | Yaw速度环PID，各0～10000 |
| `pid.speed.kp.pitch`、`pid.speed.ki.pitch`、`pid.speed.kd.pitch` | Pitch速度环PID，各0～10000 |
| `pid.angle.kp.yaw`、`pid.angle.ki.yaw`、`pid.angle.kd.yaw` | Yaw角度环PID，各0～10000 |
| `pid.angle.kp.pitch`、`pid.angle.ki.pitch`、`pid.angle.kd.pitch` | Pitch角度环PID，各0～10000 |
| `limit.current.yaw`、`limit.current.pitch` | 相电流输出限值，0～1.65A |
| `limit.speed` | 速度限值，>0且≤1000rpm |
| `limit.pitch.deg` | 机械中心两侧Pitch范围，>0且≤60°；该参数用度 |
| `uart.baud_rate` | USART10波特率，50000～5000000的整数，保存并重启后应用；不改变USB物理速度 |
| `motor.direction.yaw`、`motor.direction.pitch` | 控制方向，仅1或−1；修改清除方向确认标记 |
| `imu.map.x`、`imu.map.y`、`imu.map.z` | 轴映射，使用±1、±2、±3，不重复；修改清除方向确认并重新初始化姿态 |

以上是输入合法范围，不是全范围硬件运动验收结果。负PID、非有限数及未知键被拒绝。

普通参数操作示例（数值只是示例，不代表应覆盖现场）：

```text
disable
config --list
config limit.current.yaw 0.2
config limit.current.pitch 0.2
config limit.speed 100
config limit.pitch.deg 57.2958
config --list
```

## 💾 保存、恢复默认与重启

| 命令 | 行为 |
|---|---|
| `store` | 提示确认，30秒内输入 `y` 保存当前参数；`n`取消，超时取消 |
| `restore` | 提示确认，`y`恢复默认并自动触发保存；`n`取消，超时取消 |
| `reboot` | 失能并重启主控，USB需重新连接；不自动保存未保存修改 |

保存示例，一条一条发送：

```text
disable
store
```

看到 `(y/n)` 提示后再输入：

```text
y
```

等待 `Store configuration completed`，再读取：

```text
config --list
diag
```

取消保存或恢复默认时输入 `n`。确认阶段只输入选择，不输入其他命令，避免其中的字母被当作确认。

**恢复默认会覆盖运行参数并自动保存，不作为普通停止或故障排查步骤。** 当前源码默认限速50rpm、Pitch±30°、双轴电流限值0.20A；保留已有零点、机械中心、标志、映射和方向。默认值不是当前已保存参数。

如需验证重启持久化，保存成功后执行 `reboot`，重新连接网页，再执行 `version`、`config --list`、`diag`。重连不会自动使能。

## 📍 标定与方向命令

| 命令 | 行为与注意事项 |
|---|---|
| `config zero_pos` | 将当前双轴编码器角设为关节零点并触发保存；已有效标定时保留机械中心，首次无有效零点时同时建立中心 |
| `mechanical_center` | 将当前姿态设为双轴零点，并把当前Pitch编码器角设为机械中心，触发保存 |
| `imu_axes X Y Z` | 一次设置完整有符号轴映射，清除方向确认并重新初始化姿态；需合法右手映射 |
| `confirm_axes` | 在失能、传感器健康时设置方向确认标记；只改RAM，核验后用 `store` 保存 |

这些命令用于标定，不用于日常回零。`ctrl angle 0 0` 是运动回零；`config zero_pos` 是改写“零在哪里”。现有标定尚无完整无损恢复闭环，不要为了试命令重设零点或机械中心。

当前历史已核实的映射示例是 `imu_axes 2 -1 3`，但不是要求重新执行或覆盖当前现场。单键映射修改可能因中间状态轴重复而被拒绝，完整映射优先用 `imu_axes`。

## 🛠️ 故障、存储与激光

| 命令 | 作用 |
|---|---|
| `clear_fault` | 失能且反馈/IMU健康时清除锁存故障；不会自动使能 |
| `flash_read OFFSET` | 从参数区相对偏移读取32字节，返回 `FLASH OFFSET` 和64个十六进制字符；整数偏移0～8160 |
| `storage_claim` | 失能且未保存时授权后续存储写入；仅在完成并检查备份后使用，不会替你生成备份 |
| `enable_laser` | 当前无激光硬件，返回失败 |
| `disable_laser` | 关闭激光状态 |

故障处理先收集状态：

```text
disable
diag
status
```

排除故障原因且反馈恢复后，才按需要执行 `clear_fault`，再用 `diag` 核对；不把清故障当持续重试运动的方法。

只读Flash示例：

```text
flash_read 0
flash_read 32
```

这两条只读64字节，**不是完整备份**。完整参数区为8192字节，需要从0到8160按32字节收集并验证；当前没有网页原始Flash写回命令，不能声称已有完整恢复路径。

## 📌 网页按钮与命令的关系

| 网页操作 | 对应设备命令 / 行为 |
|---|---|
| 读取设备信息 | `version`、`info` |
| 读取状态 | `status` |
| 读取参数 | `config --list` |
| 使能 / 失能 | `enable` / `disable` |
| 复位IMU / 设置零点 | `config zero_pos --imu` / `config zero_pos` |
| 开启 / 关闭自稳 | `enable_stability` / `disable_stability` |
| 打开 / 关闭激光 | `enable_laser` / `disable_laser` |
| 模式数值发送 | 相应 `ctrl` 模式，数值顺序Yaw、Pitch |
| 参数设置 | 相应 `config KEY VALUE`，网页可能批量发送双轴字段 |
| 储存 / 恢复默认 | `store` / `restore`，设备仍需确认 |
| 重启设备 | `reboot` |
| 连接 / 断开 / 清屏 | 网页串口或本地显示操作，不是运动命令 |

USB控制源下网页断开会清除目标并失能；UART控制源下USB断开不抢占UART。正常失能不主动保持力矩，重连后需显式使能。

命令出现 `failed:` 或 `Command not Found` 时看完整回显，并用 `diag` / `status` 核实实际状态，不以“已输入”判断执行成功。不要盲目重复步进、设零或保存操作。
