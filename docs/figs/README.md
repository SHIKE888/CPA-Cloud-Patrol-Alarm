## 重新生成

```bash
cd 08_csi2rk_mipi_imx415
python tools/make_paper_figs.py
```

依赖：`matplotlib`（仅此一项；中文使用系统「微软雅黑」，找不到时回退 SimHei / Noto Sans CJK）。

## 修改约定

- 字号、配色、行距集中在脚本顶部（`LSP`、`SENS/FGP/RKI/BIZ/ACT/NEU/CLD`）。
- 每个图的函数独立，改内容只动对应 `fig_*` 函数。
- `EXT` 记录绘制内容的纵向范围，`save()` 会自动裁掉上下空白，不必手工调画布高度。
