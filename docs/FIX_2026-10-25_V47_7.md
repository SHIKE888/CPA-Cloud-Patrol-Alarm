## 1. 窗口相位：`o_rgb` / flags 从 d4 改回 d3（修 4/8 像素错位）

### 根因

`preproc_win3x3_rgb.v` / `preproc_win3x3.v` 里，窗口中心 `cu = c_p1` 的延迟是 **3 拍**
（`c_p1 <= wC`，`wC = cur_d2`，`cur_d2` 是 `rgb4` 的 2 拍延迟，再经 `WINR` 寄存 1 拍），
但像素与标志走的是 **d4 = 4 拍**。

→ **像素/行标志比窗口中心领先 1 组（4 像素）**。

原文注释写的是"WINR 再寄存一级，所以像素必须走 d4 才同拍"——`lcnt_d3`
（行号掩码用的就是 d3）恰好证明作者本来取的是 d3 相位，d4 是个笔误。

### 两条错误叠加

- 初级层：原图备份 `org*` 取自 `w_rgb`（= `o_rgb`），滤波结果取自窗口。
  两者错 1 组 → `mix8` 混的是**不同列**；级联时每级再错 1 组 → 5×5 错 4 像素、7×7 错 8 像素。
- 高级层：`preproc_edge` 的 mode 0 直接把 `i_rgb` 输出（正确），
  mode≠0 用窗口算（错）→ 一开高级算法整幅左移 4 像素。

### 修法（两个模块相同）

```verilog
o_tvalid <= v_d3;   o_tuser <= u_d3;   o_tlast <= t_d3;   // 原来是 d4
o_rgb    <= rgb_d3;                                     // 原来是 rgb_d4
```

改完 `o_rowmask`（本来就用 `lcnt_d3`）与窗口、像素、标志全部同拍。

### 验证（新增 `tb_shift.v`：宽脉冲 + 亮度重心）

原有 `tb_align*` 用逐像素绝对值比对，**整幅平移时会被误判成 PASS**，这是这个 bug 藏了这么久的原因。
`tb_shift` 用 20 像素宽脉冲，测输出亮度重心相对输入的位置：

| 用例 | 修复前 | 修复后 |
|---|---|---|
| 直通（参考） | 99.5（真值） | 99.5 |
| 高斯 3×3 | **95.2（−4.2 px）** | 99.2（−0.3 px） |
| 高斯 5×5 | **95.0（−5.0 px）** | 99.0（−0.5 px） |
| 高斯 7×7 | **94.7（−5.7 px）** | 98.7（−0.8 px） |
| 高级-中值 | **91.5（−4.5 px）** | 99.5（**0**） |
| 高级-Sobel | 91.0（−5.0） | 99.0（−0.5，阈值化量化） |

回归：`tb_align` / `tb_align2` / `tb_align3` 全部 `bad = 0`。

> 残余 0.3~0.8 px 随级联遍数单调增长，量级 ≈ 每遍 0.25 px，
> 来源是 `(sum + 8) >> 4` 的截断在每一遍各引入一次亚像素偏置，肉眼不可见。

## 2. 单色强制无色（一次消除所有单色偏色）

`rgb_to_yuv422_quad.v` 增加 `i_mono`，为 1 时直接 `cb = cr = 128`：

```verilog
cb[k] <= i_mono ? 8'd128 : (...);
cr[k] <= i_mono ? 8'd128 : (...);
```

`system_top.v` 统一判定（一处定义、两处使用）：

```verilog
wire S_mono_pp = (S_pp_mode != 4'd0) || S_basic_en[0];   // 高级任算子 或 初级-灰度
```

同时把 `preproc_post` 的白平衡旁路也改用它 —— 上一轮只覆盖了高级层，
实测 `灰度 + WB200%` 仍会 `R−G = +54.95`。

> 为什么用"强制"而不是继续追根因：实测已排除白平衡（回读 128 identity）、
> YUV 定点（灰度在 16 个亮度桶里 `max|R−G|` 全为 0）、软件 JPEG（同一有损编码器下灰度仍为 0），
> 但 **Sobel/Prewitt 送进 YUV 的像素是否真是 R=G=B 还没能证实**。
> 强制色度 128 与根因无关、代价为零，先把这个可见缺陷关掉。

## 3. HE 对比限制默认值 255 → 8

板上实测（`HE255 clip255` vs `clip8`）：

| | clip 255 | clip 8 |
|---|---|---|
| 时域噪声 `tnoise` | 13.33 | **7.33** |
| 噪声 p99 | 213 | **70** |
| 平均亮度 | 131.2 | 98.4 |

改动：`jpeg_regfile.v` 复位值、`mipi_viewer.html` / `console.html` 滑条默认值、
`mipi_webstream.py` 的 `he` 预设。

配合已有的 LUT 斜率硬限制（3）+ 帧间 1/4 IIR，三层一起压噪。
