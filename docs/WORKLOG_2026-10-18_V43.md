# V43 (2026-10-18) 4K 斜向撕裂根因与修复

## 1. 结论（一句话）

4K 画面撕裂**不是** MIPI/DDR/VTC 的问题，而是 `csi2_pack_yuv422_stream`
**每行多送出 1~2 个 32-bit word**：4K 一行 1920 word，多 1 word = 2 像素，
2160 行累计 4320 像素 > 一帧宽(3840)，于是画面出现斜坡重复（"扇型"撕裂）。

## 2. 证据链（板上，可复现）

| 步骤 | 方法 | 结果 |
|---|---|---|
| ① 静态帧 | 切 4K25、停 web、`v4l2-ctl --stream-count=1 --stream-to` 抓 3840x2160 NV16 | 16,588,800 B，bytesperline=3840（排除 stride 假象） |
| ② 逐行相位 | 相邻行 FFT 循环相位相关，y=200..1950 共 36 个采样点 | **恒为 +2 像素，std=0** |
| ③ 多种行距 | NCC / 相位相关，间隔 20/40/80/200/400 行 | 均为 **≈2.05 px/row**，线性 |
| ④ 反变换验证 | 对原帧做 `row i` 左移 `k*i` 像素，k=−4..+4 拼 3×3 网格 | **k=+2 一格画面完全正常**（灯是矩形、横幅文字水平），k=0/+1/+3 均畸变 |
| ⑤ 对照 | 同一次会话连续抓 1080p / 4K 原始帧 | 1080p 无此现象 |

> 由 ④ 可确定：真实错位 = 每行 1 个 32bit word（2 像素），方向为内容随行右移。

## 3. RTL 定位（逐段排除）

- `ui_dbuf` 写侧：`W_XSIZE=960`(64b beat) × XDIV=2 → 7680 B/行 ✓
- `ui_dbuf` 读侧：`R_XSIZE=1920`(32b word) × XDIV=2 → 7680 B/行 ✓
- `ui_VTC` de：`hcnt < 1920` → 每行 1920 拍 ✓
- `csi2_frame_tx`：`WORDS_PAYLOAD = (3840*2)/1>>2 = 1920`，每行吃 1920 个 ✓
- V32 已验证：**内置 4K TPG → TX → D-PHY → RK 干净**，TX/RK 侧排除
- ⇒ 只剩 `csi2_pack_yuv422_stream`

## 4. iverilog 复现（关键）

`fpga/sim/tb_gen.v`（参数化：H_ACTIVE / 行间消隐 / 下游背压）：

```
修复前：[MISMATCH] line 0 output_words=1922  head=0,1,2,3  tail=1918,1919,1919,1919
        [W] line 0 written=1921    (写侧也多！)
```

两个彼此独立的成因：

1. **写侧幻影 word**
   `a_rd_en` 是寄存在 `dst_clk` 的**读请求**，但 `pipe_in_valid <= a_rd_en_d1`
   把它当成"确实读到了一个 word"。FIFO 已经抽空的那一拍，FIFO 内部
   `do_read = rd_en & ~empty` 并不成立，可流水线仍然多出一个 word（内容是
   `a_dout` 旧值）。
   修：`a_rd_en_d1 <= a_rd_en & ~a_empty;`

2. **读侧重复送**
   旧实现 `m_tvalid = line_active`，与 FIFO 里有没有数据无关。
   4K 一行 1920 word，卸完一行刚好把 B-FIFO 抽空：
   - `drain_done` 那一拍 `m_tvalid` 还挂着 → 多送 1 个
   - 紧接着的 prime 读在空 FIFO 上不生效，`b_dout` 保持旧值 → 再多送 1 个
   修：改为 **4 深输出小队列**（`qmem[0:3]` + `q_cnt` + `rd_inflight`），
   `m_tvalid` 只在队列里真有 word 时有效。

   注意 FIFO 的 `empty` 是双向指针同步（滞后 2 拍）：
   判空必须 `b_occ != 0 && ~b_empty` 一起看，否则启动时会多弹 1~2 个旧 word
   （这是第二层坑，仿真里表现为第 0 行仍多 1 个）。

## 5. 为什么只有 4K 犯、为什么 V42 加深 FIFO 无效

- 1080p 一行 960 word，B-FIFO 门限 1900，常驻近满 → 抽不空 → 不触发
- 4K 一行 1920 word，门限 `max(1900, 1920+64)=1984`，卸完即空 → 每行触发
- V42 只把 FIFO 加深到 4096，**门限没变**，仍然每行抽空 → "效果不变"
