# WORKLOG 2026-10-18 — V45 预处理算法分层扩展

## 目标

在现有 FPGA 预处理之前新增一级初级预处理，并按赛题要求实现：

- **初级（多选位图，可全不选）**：灰度化 / 高斯滤波 / 直方图均衡，三套硬件**并行**；
  额外并入对比度拉伸、反色。
- **高级（单选）**：Sobel / 阈值 / 形态学（原有）+ 中值 / 拉普拉斯 / 浮雕 / Prewitt / 锐化，
  全部并行、mux 选一路。
- 每个算法都有**独立参数寄存器**。

## 数据流

```
ui_isp_top → preproc_basic（5 路并行 + 位图组合）
           → preproc_win3x3 → preproc_edge（8 路并行 + 单选）
           → preproc_post → rgb_to_yuv422_quad → ...
```

初级固定组合顺序：`高斯 → 直方图均衡 → 灰度 → 对比度 → 反色`。

## 踩坑记录（重要）

1. **Verilog 上下文位宽**：写 `cl * (8'd0 - i_he_str)` 时，在 16 位上下文里
   `0 - 255` 会算成 `0xFF01` 而不是 `1`，乘法结果完全错位（现象：HE 输出变成近似取反）。
   必须显式用 9 位：`wire [8:0] he_inv = 9'd256 - {1'b0, i_he_str};`。
2. **直方图 RAM 必须先清零**：FPGA/仿真的 RAM 上电值不确定（仿真为 X），首个 LUT 高 bin 会无效。
   已加 `S_INIT` 状态：复位后 256 拍清直方图 + 把 LUT 写成单位映射，保证 HE 第一帧正常。
3. **LUT 写入不能落后一拍**：`lut[bin] <= lutv`（寄存器）会整体错位一个 bin，
   改为直接用组合值 `lutv_n`。

## V45.2 修正（板上实测驱动）

板上 A/B（同一帧快照，1080p）：

| 配置 | mean | std | \|gx\| | 结论 |
|---|---|---|---|---|
| 关闭 | 96.4 | 31.2 | 4.32 | 基线 |
| HE 255 | 96.4 | 31.2 | 4.34 | **完全没生效** |
| 高斯 8 | 95.9 | 31.3 | 3.13 | 生效但太弱 |
| 锐化 8 | 96.5 | 31.4 | 13.30 | 生效 |
| 拉普拉斯 5 | 0.0 | 0.0 | 0.00 | **几乎全黑** |

离线对照 `cv2.equalizeHist`：std 30.5 → **75.3**，说明 HE 本应有非常明显的效果。

### 根因与修正

1. **HE 完全失效**：`ui_isp_top` 的 `O_tlast` 在 `ui_awb.v:303` 被改成
   `(valid 下降沿)` = **帧尾脉冲**，不是行尾。原来按 tlast 数行永远到不了 `v_active`，
   `build_req` 不触发，LUT 一直是单位映射。
   → 改为**按像素组计数分帧**（每行 `h_active/4` 组，累计 `v_active` 行）。
2. **高斯太弱**：3x3 只平滑 1 像素。→ 改成**两遍 3x3（等效 5x5）**，
   强度 1..4 = 原图→一遍，5..8 = 一遍→两遍。
3. **拉普拉斯/Sobel 几乎全黑**：自然图像梯度只有 20~60，右移 3 位后只剩 2~8。
   → 参数语义从“右移”改为**增益**：`out = clamp(mag * gain / 4)`，范围 1..16，默认 8。
4. **锐化范围翻倍**：`out = c + d*gain/16`，gain 1..16，默认 8。
5. **LUT 对齐**：LUT 读延迟 1 拍，延迟链只能 3 级（其他信号 4 级），否则整组像素错位
   （现象：输出在词边界出现 254/0/1/255 的错位值）。
6. **UI 统一**：所有预处理改成“一个按钮 + 选中后下面显示自己的滑条”，
   初级按钮可多选、高级按钮单选；不再使用复选框。

### 回归

- iverilog：灰度 64/192 → `0x40/0xC0`；HE → `0x00/0xFF`；两遍高斯边界 152。
- `preproc_top` / `cfg_ctrl_top` 语法通过。
