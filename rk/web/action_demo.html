⑥ 几何规则 vs 模型

几何规则（旧）
轻量模型（新）
idle 循环里的走路摆臂 / 挠头 / 抱臂是日常小动作： 几何规则会把它们当作挥砍、拍照、举手，模型因为学过 idle 不会。

④ 模型输入张量　(1, 32, 17, 3)　列 = 时间帧，行 = 关节，颜色 = X 坐标

越红 = X 越靠右；越蓝 = 越靠左；灰 = 该关节无效(valid=0)。 时间从左（旧）到右（新）。这一块就是喂给 action_net.rknn 的全部输入 —— 没有图像，所以多人时每人一次前向也几乎不花钱。
